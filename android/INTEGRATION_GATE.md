# Integration gate

The native architecture is being extended without adding fabricated content.

Required before claiming a content-complete build:
1. locate the actual supplied Marrow content package;
2. validate its MCQ/module schema against the recovered contract;
3. register it through the content boundary;
4. connect native resources/layouts;
5. perform an actual Android build/runtime verification.

Until those gates pass, the repository is an implementation foundation, not a claimed finished APK.
