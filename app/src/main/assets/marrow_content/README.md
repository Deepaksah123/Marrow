# Marrow Content

This folder is the editable local content source for the Marrow reconstruction.

- `Brain/Marrow/Edition 8 qBank/` — Edition 8 QBank JSON files
- Other Marrow datasets are kept in their own subfolders when materialized.

Edit the JSON source files here to update questions/options/answers/solutions. The native importer reads the local app content; no runtime Marrow server is required.
